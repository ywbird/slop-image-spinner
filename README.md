# slop-image-spinner

드랍한 이미지 파일을 제자리에서 회전하는 GTK3 앱.

```
┌───────────────┬───────────────┐
│      ↺        │      ↻        │  반시계 90° / 시계 90°
├───────────────┴───────────────┤
│              ⇅                │  180°
└───────────────────────────────┘
                          0        실행 중인 작업 수
```

## 실행

```sh
uv run spinner.py
```

## 동작

- 파일 URI(`text/uri-list`)를 받는 드래그드랍만 지원.
- 회전은 파일별 서브프로세스에서 실행 → UI 안 멈추고 여러 개 동시 처리.
- 원본 파일을 같은 디렉터리 temp에 저장 후 `os.replace`로 교체. 실패하면 원본 유지.
- EXIF orientation 먼저 적용(뷰어 이중 회전 방지), ICC 프로필·파일 권한 유지.
- animated GIF/WebP, 지원 안 하는 확장자는 건너뛰고 stderr에 출력.

## 테스트

```sh
uv run spinner.py --selftest
```

회전 방향, 권한 보존, temp 잔여물 없음, 깨진 파일 보존 확인.

## 한계

- JPEG/WebP는 quality 95로 재인코딩 → 드랍마다 미세 손실.
- 같은 파일을 처리 중에 다시 드랍하면 두 워커가 경쟁해 2회 회전될 수 있음.
- 워커 수 제한 없음.
